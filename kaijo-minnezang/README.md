# 海城のミンネザング — 3Dプレイアブルモック 0.5

ビルド不要・外部依存なしのWebGL 3Dゲーム。騎士名と数値は仮設定です。

## 0.5の変更点

- **ドラマパートの最小版**：出撃前のプロローグと、結果に応じて台詞が変わるエピローグ。オウガバトル風の「ドラマ → 戦闘 → ドラマ」の一巡を体験できます。
- **戦果報告と評価**：勝利時はS〜Cで評価します。評価には残存耐久、連携回数、PERFECT回数、撃破時間、難易度が反映されます。連携・被害・蓄血などの統計と、次の戦いへの助言を表示。難易度ごとの最高評価をブラウザに保存します。
- **難易度**：見習い／正騎士／誓約。敵の体力・威力・攻撃間隔が変わります。
- **第二形態の新攻撃〈血潮の墜落〉**：薙ぎ払いと交互に使用。足元の血が最も濃い艦を狙う円形の叩きつけで、円内の血域を吸い上げて回復します（1回につき最大体力の7%まで、第一形態には戻りません）。血を吸うほど狙われるため、血域の取り合いが生まれます。
- **キャンペーン層の分離**：`campaign.mjs` は `Battle.report()` の戦果だけを受け取り、台詞・助言・記録を扱います。戦闘内部の状態には触れません。

## 画面UI

スマホのアクションゲーム風の全画面HUD。戦場を画面いっぱいに表示し、操作類は重ねて配置しています。

- 上中央：ボスHP（遅れて減るダメージ表示つき）、失血ピップ、タイマー。攻撃予兆中は技名と残り秒数の警告帯と、画面外周の赤いビネットを表示
- 左：目標ピル、戦況ログのトースト。左下に三騎士のロスター（HP・蓄血）
- 右下：再生／停止の大ボタンを中心に、Q/W/Eのスキル円（クールダウンの円弧、予約中は金色）、旗命令1/2/3と助走点の小ボタン
- カットイン：騎士色の斜めパネル、閃光ライン、四芒星。立ち絵の代わりに紋章を表示
- 3Dの予兆：塗りの濃い扇形・円、破線の縁、発動までの進行を示す塗り、ひび割れ線
- 設定と遊び方は左上の☰メニューに格納

## 3D表示とカメラ

海城（城壁・尖塔・旗・杭発射機・巨槍・盾）、二本腕のネフェリム、血海の拘束杭を実際の3Dメッシュで表示。水面は波と血液濃度をシェーダー描画します。ドラッグで旋回と俯角変更、ホイール・ピンチ・＋／−でズーム、視点リセットで初期状態に戻ります。ドラッグ後のクリックを命令として誤認しないよう抑止し、海面とのレイ交差から集合・助走地点を決定します。

## 遊び方

戦闘開始後、通常の杭が失血を作るとイベントポーズ。Q/W/Eまたは各騎士のボタンでスキルを予約して再開すると、連続紋章カットイン後に同一戦闘時刻から技が始動します。Spaceは停止・再開、1/2/3は突撃・集合・死守。集合旗選択後、海図クリックで集合地点を自由指定。ジョスト助走点もポーズ中に指定できます。未指定で近すぎる場合は自動で助走距離を確保します。

- **茨卿〈縫い留め〉**：足元に血域のある敵を10秒拘束。血海から杭が現れ、移動・旋回を封じます。腕の攻撃は止まりません。
- **白鷺卿〈ジョスト〉**：助走で加速し、基礎威力＋速度加算。射出集中時にFまたはボタンを押し、金色の範囲なら1.5倍。未入力・失敗でも通常射出。入力自動補助あり。命中で押し戻しますが、薙ぎ払い中は敵の耐性が優先します。
- **赤楯卿〈不退の誓い〉**：8秒間、半径235以内の味方の被害軽減とノックバック無効。自身も含み、通常移動は妨げません。
- **連携**：縫い留め＋ジョストの同時予約。拘束中にジョストが命中すると杭を破砕し、追加失血・血域拡大。拘束を解除して押し戻します。

ネフェリムは低速で移動し、腕の広範囲薙ぎ払い時は停止。予兆で範囲と向きを固定しイベントポーズ。実行後3.5秒の後隙。離れた敵には威力控えめの遠距離攻撃。体力50%で第二形態となり、〈血潮の墜落〉を交互に使います。

血域は海面に残り、中心ほど濃く、24秒で薄れます。吸血で各海城に最大100を蓄え、25ごとに役割に応じた強化。離脱しても維持し、再挑戦でリセット。味方同士で血を奪い合わず、スキルは蓄血を消費しません。定期ポーズはありません。

## 構成と検証

`dist/battle.mjs`はDOM非依存の戦闘処理、`render3d.mjs`はWebGL描画とラベル・カメラ、`scene3d.mjs`は立体モデルと演出、`space3d.mjs`は座標変換と形状、`shaders3d.mjs`は照明・海面・血域、`app.mjs`は操作・HUD・演出時間管理、`campaign.mjs`はプロローグ・エピローグ・助言・記録保存。カットイン中は戦闘時間停止。射出集中では戦闘速度0.12倍、手動・イベントポーズ中は入力の時間も停止します。

- `node tests/combat.mjs`：血域の濃度と残留、蓄血維持、ポーズ、同時発動、拘束、射出入力、ノックバック、連携、勝敗、難易度、〈血潮の墜落〉の標的・吸血、戦果報告と評価を検証。
- `node tests/campaign.mjs`：勝敗別のエピローグ、助言、記録保存（敗北で勝利記録を上書きしない、保存不可の環境でも動く）を検証。
- `node tests/ui-smoke.mjs`：簡易DOM、WebGL呼び出しアダプターと実際のイベントハンドラーでカメラ・出撃、予約、カットイン、入力、集合、初期化を検証。
- `node tests/geometry3d.mjs`：324組のカメラ条件と海面座標の往復変換、全メッシュの有限値を検証。ネイティブ描画用シーンを一時領域へ出力。
- `python tests/native3d.py`：同じシェーダー・メッシュ・カメラでEGL/OpenGL ESによるオフスクリーン描画を実行し、シェーダーのコンパイル、リンク、GLエラー、白紙出力を検証。
- `tests/render.mjs` と `dist/render.mjs` は旧2D版の検証用。現在のゲームでは読み込みません。

ネイティブ3D描画結果の目視確認済み。ブラウザ実機での操作・レイアウト確認は未実施。カットインは騎士の紋章による仮演出。音声、キャラクター立ち絵、本格的なドラマパート（分岐・編成）はまだ含みません。


## ローカルで起動する

Python 3 がインストールされている環境で、リポジトリのルートから実行します。

```sh
python3 -m http.server 8000 --directory kaijo-minnezang/dist
```

ブラウザで http://localhost:8000 を開いてください。ES Modulesを使うため、HTMLファイルの直接オープンではなくHTTPサーバー経由で起動します。ビルドやnpm installは不要です。WebGL対応ブラウザが必要です。

戦闘ルールと3D座標変換のテストは、Node.jsで実行できます。

```sh
cd kaijo-minnezang
node tests/combat.mjs
node tests/campaign.mjs
node tests/geometry3d.mjs
```

UI・画像の検証は任意で、`@napi-rs/canvas`、PythonのPillow、LinuxのEGL/OpenGLなど追加の環境が必要です。これらはゲームを遊ぶためには不要です。
