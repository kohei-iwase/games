# 海城のミンネザング 設定資料（第二稿）

この資料は世界観・キャラクター・トーン・音楽の基準をまとめる。**【確定】** はユーザーが決めた事項、**【案】** は検討中の提案で、採否が決まり次第書き換える。

## 1. 方向性

【確定（2026-10-12 改訂）】普段はコメディ寄りのファンタジー、要所はシリアス。見た目（深紅・金・耽美な絵）は残し、中身とのギャップを楽しむ。以下は初期の方向性（参考として残す）：耽美で華やかなロマンス。参考イメージは『常夜国騎士譚RPG ドラクルージュ』（明けない夜の世界の吸血鬼の騎士たちの物語）と『プリンセス・プリンシパル』（姫を中心にした宮廷の華やかさと、登場人物それぞれの秘密やほろ苦さ）。

### テーマ

【確定】
- **名前の継承**：騎士の名・称号・海城は受け継がれる。継ぐことは、先に背負っていた者を失うことでもある。
- **ノブリス・オブリージュ**：騎士と姫の両方が、高貴さに伴う義務と代償を負う。騎士は最愛の人を海城の心臓に捧げる代償を負って島々を守り、姫もまた自ら心臓になることを選ぶ（プレイヤーの姫も、プロローグでその選択をする）。守られる島の人々は、その代償を知らない。

【案】
- 騎士たちは島の人々に代償を語らない。「知らなくていい。それが騎士だろ」（ミラルカ）。称えられることも、恐れられることも、黙って引き受ける。
- 名前の継承【案・改訂】：皇帝の名を捨てて「ミラルカ」として隠れ住んでいた主人公が、もう一度名を刻む（「刻めよ、我が名を」）。空いた玉座を誰が継ぐのか、も物語の軸になりうる。
- ノブリス・オブリージュ【確定・改訂】：責務を捨てたかつての皇帝が、守られる側の市民（主人公）の無私の行動を見て、高貴なるものの責務を思い出す。

## 2. 世界観

### 帝国と遠征（2026-10-12 改訂）

【確定】
- 世界には**皇帝**がおり、それに付き従う**諸侯**がいる。ただし皇帝の座は、いまは空席になっている。
- **ネフェリム**は天変地異を引き起こし、洪水を起こして世界の水位を上昇させる巨人。世界の大半が海に沈んだのは、ネフェリムのため。
- 約50年前、皇帝は艦隊を率いて**遠征**（十字軍のような大遠征）を行った。遠征のあと、ネフェリムの出現しない平和な時期がしばらく続いた。
- 凱旋した皇帝は、ほどなく行方不明になった。謀殺された、呪いを受けた、などさまざまな噂が飛び交っている。
- 最近になって、ネフェリムの復活の予兆が現れはじめている（潮が高くなる、沈んだ谷が泡立つ）。

【案】
- 遠征の勝利は、皇帝の姫と配下のほとんどの命と引き換えだった。民はその代償を知らず、「皇帝がネフェリムを討った」とだけ伝わっている。
- 皇帝の不在のあいだ、諸侯は互いに牽制しあい、玉座は空いたまま。ネフェリムの予兆を受けて、諸侯の一部が動き出している（カナンの主君もそのひとり）。

### 舞台

【確定】海面が上昇し、世界の大半が海に沈んでいる。かつての山の山頂部分だけが島として点在している。

【確定】主人公がいるのは、かつて皇帝の艦隊が遠征前に**最後に立ち寄った、世界の果ての小さな島**（ゲーム内では「峰の灯の島」）。丘の上に廃教会があり、ミラルカが住んでいる。

【確定】次の話の舞台は、カナンが仕える諸侯が治める、発展した島。

【案】
- 人々は山頂の島々に身を寄せて暮らし、島と島のあいだを行き来できるのは海城だけ。
- 島の名は、沈む前の山の名を受け継ぐ（例：「〇〇峰」）。海図には海の下の山脈や、沈んだ都の尖塔が見える。
- 第一話「第一歌　血海の誓い」【ゲームに反映済み】：ネフェリムが沈んだ谷の底から浮上し、果ての島の灯を目指して迫る。島の沖には沈んだ尾根の浅瀬が点在し、巨体のネフェリムは足を取られて動きが鈍る。

### 姫と海城

【確定】
- 騎士は海に浮かぶ城「海城」に乗って戦う。海城を動かしているのは、騎士にとって唯一無二の大切な存在「姫」である。
- 操作できる騎士には、それぞれ自分の姫がいる。
- 姫はもとは普通の人間（または生き物）で、その者が騎士に任じられたときの特別な儀式によって、海城の心臓部に姿を変えている。
- 姫は女性とは限らない。男性も動物もいる。

【案】
- 儀式の名は「心臓の叙任」。騎士の誓いと引き換えに、姫が海城の心臓になる。騎士の称号（〜卿）はこのときに授かる。
- **血と歌**：心臓になった姫は、血によって鼓動する。騎士が血の海から血を集める（ゲーム内の蓄血）のは、姫を生かして城を動かすため。そして騎士が姫に捧げる恋歌（ミンネザング）が、姫に人であったころの記憶をつなぎとめる。

【保留・裏設定候補】表には出さず、今は保留する。
- **代償**：歌が途絶えた姫は、自分が誰だったかを忘れ、血を求めるだけの心臓になる。そうなった海城は騎士を失っても動き続け、やがて怪物になる。
- **ネフェリム**：歌を失った海城の成れの果て。かつて誰かの姫だった心臓が、海の底で巨人の姿をとったもの。倒すことは敵を討つことであると同時に、ひとりの姫を眠らせることでもある。

【案】
- **常夜の海**：夜が明けない海。血の海が広がるほど夜は深くなる。夜が明けない理由は、物語全体の謎として後で決める。

### ゲームの仕組みとのつながり【案】

| 仕組み | 物語上の意味 |
|---|---|
| 蓄血（血域から血を吸って強化） | 姫に血を捧げ、鼓動を強める |
| 海城の耐久 | 姫の命。撃沈は姫を失うこと |
| 旗艦（ミラルカ）の戦闘不能で撤退 | 旗艦の姫を失えば艦隊は進めない |
| スキル・カットイン | 騎士の誓いと、心臓部で応える姫の姿 |
| ネフェリムの第二形態・血潮の墜落 | 姫だったころの記憶の残り火が暴れる |

## 3. キャラクター

### 主人公

【確定】**ミラルカ**。ゲーム内の表示は二つ名なしの「ミラルカ」。旗艦の騎士で、プレイヤーが操作するキャラクター。姫はプレイヤー（下記「プレイヤー（姫）」）。

![ミラルカ（参考画像）](images/miralka.png)

- 外見：銀の長髪、赤い瞳、笑うと牙がのぞく。ほつれた黒い修道女のヴェール（白い額帯つき）と黒い修道服。背後に木の十字架と棺。
- 戦い方：ジョスト（助走して撃ち込む一撃）。十字架を巨大な杭として棺から撃ち出す。
- 旗艦の色：銀と深紅。画面上の印（名簿・海図・ラベル）は敵の赤と紛れないよう銀。3Dの海城は深紅の船体に銀の縁取り、旗は深紅。
- 口調【確定】：勇ましく、ボーイッシュで幼さが残る。一人称「ボク」、姫（プレイヤー）は「キミ」と呼ぶ。
- カットイン【確定】：「刻めよ、我が名を」。捨てた名を、もう一度この海に刻む宣言。

【確定】正体と過去（2026-10-12 改訂）
- 正体は、遠征から凱旋したあと行方不明になった**皇帝その人**。
- 遠征で、世界の平和と引き換えに、当時の「姫」と愛すべき配下をほとんど失った。それが世を捨てた理由。
- 姫を失った呪いで時が止まり、50年経ったいまも少女の姿のまま。
- いまは果ての小島の廃教会で、世話役に盾持ちのオリーヴェを一人だけつけ、世捨て人のような生活をしている（普段は礼拝堂の長椅子で寝ている）。
- ネフェリムの復活の予兆を感じていたが、新たに姫を設けて戦いに出るつもりはなく、世界が海に沈むのを受け入れ、争わず穏やかに過ごそうとしていた。
- 洪水に押し流されるオリーヴェを、主人公が迷わず助けようとしたのを見て、高貴なるものの責務を思い出し、気が変わる。主人公を新たな姫にし、再び海へ出る。

【案】
- 正体は周囲に伏せている。カナンが「陛下」と呼びかけると慌ててごまかす（コメディの定番にする）。主人公には物語の要所で明かす。
- 「ミラルカ・フォン・ノア」の名、皇帝としての本名をどう扱うかは後で決める。

### プレイヤー（姫）

【確定】
- プレイヤーは新しい姫。名前はプレイヤーが付け、最初に性別（姿）を選ぶ。会話画面に立ち絵で登場する。
- 物語の始まりでは、果ての島（峰の灯の島）に暮らす普通の市民で、灯台守の見習い。廃教会へ届け物をする縁でミラルカとオリーヴェを知っている。
- プロローグで、ネフェリムの予兆の洪水にさらわれたオリーヴェを迷わず助けようとし、その善性がミラルカの心を動かす。ミラルカの海城の心臓（新たな姫）になる。
- 心臓になった姫は、船魂（ふなだま）のような存在になる。海城に宿ってその心臓として城を動かしつつ、人の姿をとって城の外でも活動できる（島に降りる、騎士と並んで歩く、など）。城の中では半透明の幻影として現れることもある。
- ゲームの仕組みとの対応：戦略マップの俯瞰は姫の視点、艦隊への指示は姫の声、ジョストのタイミング入力は騎士と鼓動を合わせること、会話では騎士たちが姫に話しかけ、プレイヤーは選択肢で答える。

【案】
- 人の姿でいられる時間や距離には限りがあり、城（心臓）から離れすぎると姿が薄れる。血を捧げる（蓄血）ほど姿がはっきりする。
- 普通の市民なので、騎士たちの常識（心臓になること、血の海）にいちいち驚く。コメディではツッコミ役。

### 騎士・従騎士

【確定】操作できるのは、ミラルカ（旗艦・ジョスト）、老騎士カナン（杭・縫い留め）、盾持ちオリーヴェ（盾持ちの従騎士・防護）の三人。表示名は `battle.mjs` の `NAMES` で管理する。

#### 老騎士カナン

【確定】
- 50年前、皇帝（ミラルカ）の従騎士だった。若すぎたため、遠征には連れて行かれなかった。
- 皇帝が行方不明になったあと、別の諸侯の騎士となった。
- ミラルカとは50年ぶりの再会。ミラルカは船の紋章を見て「その紋章……カナンの坊やか」と気づく。
- 物語では、チュートリアルの最中に合流する（ネフェリムの予兆を受け、主君の命で果ての海を見回っていた艦隊として現れる。台本 `dist/story/join-kanaan.txt`）。
- 戦闘では杭で敵を縫い留め、失血させる。イメージカラーは赤銅色。

![老騎士カナン（参考画像）](images/kanaan.png)

- 外見：赤と白の混じった髪、赤い瞳、白い髭。深い皺と鋭い目つき。焦げ茶の外套と襟巻き、籠手。
- 口調：とぼけたじいさん寄りで、語尾は「〜じゃ」「〜かの」、一人称「わし」。ミラルカを「ミラルカ殿」と呼ぶ（うっかり「陛下」と言いかける）。昔は泣き虫だった、とミラルカにからかわれる。
- カットイン：「老いぼれの杭、まだ錆びてはおらぬ。」

【案】
- 「置いていかれた従騎士」として、ミラルカが再び海に出た理由を誰より知りたがっている。
- 主君（諸侯）の名、その島の名は次の話で決める。

#### 盾持ちオリーヴェ

【確定】盾持ちのメイドの従騎士。二つ名は「盾持ち」。イメージカラーは青。廃教会でミラルカのただ一人の世話役をしている。プロローグで洪水にさらわれ、主人公に助けられようとする。

![盾持ちオリーヴェ（参考画像）](images/olive.png)

- 外見：青い肌、閉じた目、黒髪の三つ編み。フリルのボンネットとエプロンのメイド服。片脚が機械の義足。
- 口調：丁寧で静か（「〜でございます」、一人称「わたくし」、ミラルカを「ミラルカさま」、主人公を「見習いさま」→姫になってからは「{姫}さま」と呼ぶ）。寝てばかりのミラルカへの冷静なツッコミ役。
- カットイン：「この身が、皆さまの盾にございます。」

【保留】カナンとの関係。台本ではいまは触れていない。候補：旧設定の「カナンの孫娘」／オリーヴェが母でカナンが息子（オリーヴェも何らかの理由で歳を取らない）。

### 立ち絵

【確定】立ち絵は全員、同じ絵柄で統一する：明るいアニメ塗りと水彩の中間（くっきりした線に、淡い水彩のにじみと紙の質感）。腰上・やや斜め・背景透明。元絵は `art/style-test/`（ミラルカ F1・カナン F・オリーヴェ F・姫の乙女／若人 F）。ゲームでは会話用に `dist/art/talk-*.png`、カットイン用に胸から上を切り出した `dist/art/miralka.png` などを使う。指示文は `docs/art-prompts.md`。

## 4. トーン

【確定】色と装飾は次の案で進める。

- **色**：深紅・金・象牙・夜の紺。
- **装飾**：茨と薔薇の紋様、レース、金縁。
- **文字**：明朝体を基本にし、見出しや騎士名に装飾的な書体を使う。
- **言葉づかい**：宮廷風で、やや古風。説明的なシステム文言は短く保つ。

【案】
- カットインは、今の紋章表示から、騎士の立ち絵と、その背後の心臓部に浮かぶ姫の姿を重ねる演出へ発展させる。
- 姫の心臓【確定・ゲームに反映済み】：心臓そのものは画面に見せない。被弾や危機を画面の動きで間接的に表す。旗艦が被弾すると3D画面が揺れ、続いて心臓の鼓動のように画面全体が「ドクン」と縮み、ふちが暗い深紅に沈む。僚艦の被弾は軽い揺れ。旗艦の耐久が30%以下になると、鼓動の効果音に合わせて約1秒ごとに画面が縮む。
- カットインで立ち絵の背後に姫の姿を重ねる案は保留。

## 5. 音楽

【確定】
