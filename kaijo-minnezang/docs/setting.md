# 海城のミンネザング 設定資料（初稿）

この資料は世界観・キャラクター・トーン・音楽の基準をまとめる。**【確定】** はユーザーが決めた事項、**【案】** は検討中の提案で、採否が決まり次第書き換える。

## 1. 方向性

【確定】耽美で華やかなロマンス。参考イメージは『常夜国騎士譚RPG ドラクルージュ』（明けない夜の世界の吸血鬼の騎士たちの物語）と『プリンセス・プリンシパル』（姫を中心にした宮廷の華やかさと、登場人物それぞれの秘密やほろ苦さ）。

### テーマ

【確定】
- **名前の継承**：騎士の名・称号・海城は受け継がれる。継ぐことは、先に背負っていた者を失うことでもある。
- **ノブリス・オブリージュ**：騎士と姫の両方が、高貴さに伴う義務と代償を負う。騎士は最愛の人を海城の心臓に捧げる代償を負って島々を守り、姫もまた自ら心臓になることを選ぶ（プレイヤーの姫も、プロローグでその選択をする）。守られる島の人々は、その代償を知らない。

【案】
- 騎士たちは島の人々に代償を語らない。「知らなくていい。それが騎士だろ」（ミラルカ）。称えられることも、恐れられることも、黙って引き受ける。
- 継承は「名を受け継いで先代のように生きる」ことと「受け継いだ上で自分の名を刻む」ことのあいだで揺れる。ミラルカは後者、オリーヴェは前者から始まり、物語を通して自分の答えを探す。

## 2. 世界観

### 舞台

【確定】海面が上昇し、世界の大半が海に沈んでいる。かつての山の山頂部分だけが島として点在している。

【案】
- 人々は山頂の島々に身を寄せて暮らし、島と島のあいだを行き来できるのは海城だけ。騎士は島々を守り、つなぐ存在として敬われ、同時に恐れられている。
- 島の名は、沈む前の山の名を受け継ぐ（例：「〇〇峰」）。海図には海の下の山脈や、沈んだ都の尖塔が見える。
- 第一話の舞台【案・ゲームに反映済み】：「沈みし峰々」のひとつ、ヴァルトブルク峰の沖。章題は「第一歌　血海の誓い」。ヴァルトブルクは、中世ドイツでミンネザングの歌合戦が開かれたと伝わる城の名にちなむ。ネフェリムは沈んだ谷の底から浮上し、峰の灯（島の人々の暮らし）を目指して迫る。
- 峰の灯と浅瀬【案・ゲームに反映済み】：ヴァルトブルク峰の島「峰の灯」（戦場の左端）を、ネフェリムが目指して迫る。灯が消えれば島は闇に沈み、敗北となる。島の沖には沈んだ尾根の浅瀬が点在し、巨体のネフェリムは足を取られて動きが鈍る。

### 姫と海城

【確定】
- 騎士は海に浮かぶ城「海城」に乗って戦う。海城を動かしているのは、騎士にとって唯一無二の大切な存在「姫」である。
- 操作できる騎士には、それぞれ自分の姫がいる。
- 姫はもとは普通の人間（または生き物）で、その者が騎士に任じられたときの特別な儀式によって、海城の心臓部に姿を変えている。
- 姫は女性とは限らない。男性も動物もいる。

【案】
- 儀式の名は「心臓の叙任」。騎士の誓いと引き換えに、姫が海城の心臓になる。騎士の称号（〜卿）はこのときに授かる。
- **血と歌**：心臓になった姫は、血によって鼓動する。騎士が血の海から血を集める（ゲーム内の蓄血）のは、姫を生かして城を動かすため。そして騎士が姫に捧げる恋歌（ミンネザング）が、姫に人であったころの記憶をつなぎとめる。

【保留・裏設定候補】表には出さず、今は保留する。
- **代償**：歌が途絶えた姫は、自分が誰だったかを忘れ、血を求めるだけの心臓になる。そうなった海城は騎士を失っても動き続け、やがて怪物になる。
- **ネフェリム**：歌を失った海城の成れの果て。かつて誰かの姫だった心臓が、海の底で巨人の姿をとったもの。倒すことは敵を討つことであると同時に、ひとりの姫を眠らせることでもある。

【案】
- **常夜の海**：夜が明けない海。血の海が広がるほど夜は深くなる。夜が明けない理由は、物語全体の謎として後で決める。

### ゲームの仕組みとのつながり【案】

| 仕組み | 物語上の意味 |
|---|---|
| 蓄血（血域から血を吸って強化） | 姫に血を捧げ、鼓動を強める |
| 海城の耐久 | 姫の命。撃沈は姫を失うこと |
| 旗艦（ミラルカ辺境伯）の戦闘不能で撤退 | 旗艦の姫を失えば艦隊は進めない |
| スキル・カットイン | 騎士の誓いと、心臓部で応える姫の姿 |
| ネフェリムの第二形態・血潮の墜落 | 姫だったころの記憶の残り火が暴れる |

## 3. キャラクター

### 主人公

【確定】**ミラルカ・フォン・ノア**。ゲーム内の表示は **ミラルカ辺境伯**。旗艦の騎士で、プレイヤーが操作するキャラクター（試作の白鷺卿と置き換えた）。姫は **ローラ**。

![ミラルカ・フォン・ノア（参考画像）](images/miralka.png)

- 外見（参考画像より）：銀の長髪、赤い瞳、笑うと牙がのぞく。ほつれた黒い修道女のヴェール（白い額帯つき）と黒い修道服。背後に木の十字架と棺。
- 表情：口元に挑発的な笑み。可憐さと危うさが同居する。
- 戦い方：ジョスト（助走して撃ち込む一撃）を担当する。
- 旗艦の色：銀と深紅。画面上の印（名簿・海図・ラベル）は敵の赤と紛れないよう銀。3Dの海城は深紅の船体に銀の縁取り、旗は深紅。カットインは深紅の地に白抜き。
- 姫：プレイヤー（下記「プレイヤー（姫）」）。旧設定の姫ローラは削除した。

【案】
- 名前の響き：「ミラルカ」は吸血鬼小説『カーミラ』の別名（ミルカーラ）に通じ、「ノア」は大洪水を方舟で生き延びた人物の名。海に沈んだ世界で海城（方舟）を駆る主人公にふさわしい。
- 修道女でありながら血を力にする騎士、という矛盾が人物の芯になる。
- 武器：十字架を巨大な杭として棺から撃ち出す。ゲーム内では、ジョストのダメージ表示を「十字架」、状態表示を「十字架を装填」「杭打ちの間合いへ」とした。
- 口調【確定】：勇ましく、ボーイッシュで幼さが残る。一人称は「ボク」、姫（プレイヤー）は「キミ」と呼ぶ（「全艦、ボクに続け！」「勝ちは勝ち！ ……でも次は、一発で仕留めてみせるからな。」）。姫に話しかけるときだけ、短く柔らかくなる。
- カットイン【確定】：普段の口調から一転し、凛々しく宣言する。「刻めよ、我が名を」。ミラルカのカットインに限り、この宣言を大見出しにし、技名〈ジョスト〉は小さく添える。深紅のパネルに立ち絵（参考画像の背景を除いて切り抜いたもの、`dist/art/miralka.png`）を表示する。
- 称号【案】：辺境伯は、沈んだ世界の果て、最前線の島々を預かる騎士の位。
- 継承【確定】：「ミラルカ」は本人の名。辺境伯の称号を先代から継いだ（称号だけを継いだ）。カットインの「刻めよ、我が名を」は、継いだ称号の陰に隠れず、先代とは違う自分の名を刻む宣言。
- 継承【案】：カナンは先代辺境伯の補佐役でもあり、いまのミラルカを先代と比べてしまうことがある（「先代にもお見せしたかった」）。先代が誰か（親か兄姉か）、なぜ倒れたかは後で決める。
- 後で決める：先代辺境伯の姫はどうなったか、ミラルカが称号を継いでから姫（プレイヤー）と出会うまで、心臓のない城をどうしていたか。

### プレイヤー（姫）

【確定】
- プレイヤーは新しい姫。名前はプレイヤーが付け、最初に性別（姿）を選ぶ。会話画面に立ち絵で登場する。
- 物語の始まりでは、峰の灯の島に暮らす普通の市民。プロローグでミラルカに見初められ、叙任の儀式でミラルカの海城の心臓になる。
- 心臓になった姫は、船魂（ふなだま）のような存在になる。海城に宿ってその心臓として城を動かしつつ、人の姿をとって城の外でも活動できる（島に降りる、騎士と並んで歩く、など）。城の中では半透明の幻影として現れることもある。
- ゲームの仕組みとの対応：戦略マップの俯瞰は姫の視点、艦隊への指示は姫の声、ジョストのタイミング入力は騎士と鼓動を合わせること、会話では騎士たちが姫に話しかけ、プレイヤーは選択肢で答える。

【案】
- 人の姿でいられる時間や距離には限りがあり、城（心臓）から離れすぎると姿が薄れる。血を捧げる（蓄血）ほど姿がはっきりする。
- 普通の市民なので、騎士たちの常識（心臓になること、血の海）にいちいち驚く。コメディではツッコミ役。

### 騎士・従騎士

【確定】操作できるのは、ミラルカ辺境伯（旗艦・ジョスト）、老騎士カナン（杭・縫い留め。主人公の補佐役）、盾持ちオリーヴェ（盾持ちの従騎士・防護）の三人。カナンはオリーヴェの祖父。表示名は `battle.mjs` の `NAMES` で管理する。

#### 老騎士カナン

【確定】老騎士。主人公ミラルカの補佐役で、オリーヴェの祖父。戦闘では杭で敵を縫い留め、失血させる（旧・茨卿の枠）。

![老騎士カナン（参考画像）](images/kanaan.png)

- 外見（参考画像より）：赤と白の混じった髪、赤い瞳、白い髭。深い皺と鋭い目つき。焦げ茶の外套と襟巻き、黒い衣、籠手をはめた手を剣の柄に置く。
- 口調【確定（方針転換）】：古風さは味付け程度。とぼけたじいさん寄りで、語尾は「〜じゃ」「〜かの」、一人称「わし」。辺境伯の無茶をたしなめる役（「辺境伯！　入港は徐行と、何度申し上げれば！」）。要所でだけ重みのある言葉を言う。孫のオリーヴェには短く厳しく、しかし案じる（「……オリーヴェ、前に出すぎるでないぞ。」）。
- カットイン：「老いぼれの杭、まだ錆びてはおらぬ。」。立ち絵は参考画像の上半身を切り抜いた `dist/art/kanaan.png`。
- イメージカラー【確定】：赤銅色。海城は焦げ茶の船体に赤銅の縁取り、画面上の印も赤銅色。
- 継承【確定】：オリーヴェはいずれ祖父の名「カナン」と海城を継ぐ定めにある。継ぐことは祖父を失うことでもあり、カナンの「前に出すぎるでないぞ」には、孫を案じる気持ちと、継がせる日を遅らせたい気持ちが重なる。
- 未決：姫、先代辺境伯との関係。

#### 盾持ちオリーヴェ

【確定】盾持ちのメイドの従騎士。二つ名は「盾持ち」（旧案は「堅牢なる」）。イメージカラーは青。カナンの孫娘（旧・赤楯卿の枠）。

![盾持ちオリーヴェ（参考画像）](images/olive.png)

- 外見（参考画像より）：青い肌、閉じた目、黒髪の三つ編み。フリルのボンネットとエプロンのメイド服。片脚が機械の義足。両腕を広げ、舞うような姿勢。
- 口調【案】：丁寧で静か（「〜でございます」、一人称「わたくし」、ミラルカを「辺境伯さま」、カナンを「お祖父さま」と呼ぶ）。
- カットイン：「この身が、皆さまの盾にございます。」。立ち絵は参考画像の上半身を切り抜いた `dist/art/olive.png`。
- 継承【確定】：いずれ祖父の名「カナン」と海城を継ぐ定め。いまは「盾持ち」の二つ名で呼ばれる従騎士。
- 未決：姫（旧案の「老いた猟犬」を引き継ぐかは後で決める）、継ぐことをどう受け止めているか。

### 立ち絵

【確定】立ち絵は全員、同じ絵柄で統一する：明るいアニメ塗りと水彩の中間（くっきりした線に、淡い水彩のにじみと紙の質感）。腰上・やや斜め・背景透明。元絵は `art/style-test/`（ミラルカ F1・カナン F・オリーヴェ F・姫の乙女／若人 F）。ゲームでは会話用に `dist/art/talk-*.png`、カットイン用に胸から上を切り出した `dist/art/miralka.png` などを使う。指示文は `docs/art-prompts.md`。

## 4. トーン

【確定】色と装飾は次の案で進める。

- **色**：深紅・金・象牙・夜の紺。
- **装飾**：茨と薔薇の紋様、レース、金縁。
- **文字**：明朝体を基本にし、見出しや騎士名に装飾的な書体を使う。
- **言葉づかい**：宮廷風で、やや古風。説明的なシステム文言は短く保つ。

【案】
- カットインは、今の紋章表示から、騎士の立ち絵と、その背後の心臓部に浮かぶ姫の姿を重ねる演出へ発展させる。
- 姫の心臓【確定・ゲームに反映済み】：心臓そのものは画面に見せない。被弾や危機を画面の動きで間接的に表す。旗艦が被弾すると3D画面が揺れ、続いて心臓の鼓動のように画面全体が「ドクン」と縮み、ふちが暗い深紅に沈む。僚艦の被弾は軽い揺れ。旗艦の耐久が30%以下になると、鼓動の効果音に合わせて約1秒ごとに画面が縮む。
- カットインで立ち絵の背後に姫の姿を重ねる案は保留。

## 5. 音楽

【確定】

| 場面 | 曲調 | 編成 |
|---|---|---|
| 移動・通常戦闘 | マーチ | ホルン中心 |
| 強敵戦（ネフェリムなど） | ワルツ。第二形態で転調・加速 | 弦楽中心 |
| ドラマパート | 耽美・静か | チェンバロ、弦楽 |
| 叙任・姫にまつわる場面 | 荘厳 | 聖歌隊 |

効果音：鼓動（姫の心臓。蓄血や危機で変化）、杭が海から突き出る音、槍の射出、鐘の音（戦術ポーズ）、海と風の環境音。

## 6. 未決事項

- 騎士の性別・名前・年齢と、姫それぞれの名前
- 夜が明けない理由と、物語全体の目的
- 「心臓の叙任」の採否（「歌が途絶えた姫が怪物になる」「ネフェリム＝歌を失った海城」は裏設定候補として保留）
- 先代辺境伯が誰でなぜ倒れたか、ミラルカが称号を継いだ経緯、なぜプレイヤーを見初めたか
- プレイヤーの姫の立ち絵（男女2種）
- 第一話以降のステージ構成と、ドラマパートで姫を登場させる方法（心臓部の声、回想、夢など）
