# 立ち絵の描き直し：ChatGPT（画像生成）用の指示文

立ち絵の絵柄を統一するための指示文。ChatGPT の画像生成にそのまま貼って使う。

進め方は2段階。

1. **絵柄を選ぶ**：ミラルカ1人を、4つの絵柄（A〜D）で描いてもらって比べる。
2. **全員を描く**：選んだ絵柄で（立ち絵は腰上・やや斜めで統一。カットインや表情の顔アップは、ここから切り出す）、5人（ミラルカ・カナン卿・オリーヴェ・姫の乙女・姫の若人）を描く。1枚目をできたら、以降はそれを参考画像として添付して「同じ絵柄で」と頼むと揃いやすい。

できた画像は、そのままチャットに送ってもらえれば、背景の切り抜きと縮小をしてゲームに組み込む。

## 共通の条件（全員に付ける）

```
ゲームの会話画面に使うキャラクターの立ち絵。
・腰上（頭から太ももの付け根あたりまで）。キャラクター1人だけ。
・体はやや斜め（3/4向き）、顔は正面寄りで、視線はこちら側。
・頭の大きさと目の高さを全員そろえる（目の位置は画像の上から約15%）。
・光は全員左上から。
・背景は透明（できなければ無地の白）。文字・枠・ロゴは入れない。
・縦長の画像（2:3）。
・全員を同じ絵柄・同じ線の太さ・同じ塗り方で描く。
```

## 1. 絵柄の候補（ミラルカで比べる）

ミラルカの説明：

```
キャラクター：ミラルカ。修道女の姿をした少女騎士。
銀の長い髪、赤い瞳、笑うと小さな牙がのぞく。ほつれた黒いヴェール（白い額帯つき）と黒い修道服。
背中に大きな木の十字架と、小さな棺を背負っている。勇ましく、少しいたずらっぽい表情。
差し色は深紅と銀。
```

この説明と共通の条件に、次の絵柄の指定を1つずつ足して描いてもらう。

- **A. 耽美ゴシック・厚塗り**（今の立ち絵に近い）
  ```
  絵柄：耽美なゴシックファンタジー。厚塗りで、陰影を深く、光は少なめ。落ち着いた色。
  ```
- **B. 明るいアニメ塗り**（コメディ寄りの物語に合わせる）
  ```
  絵柄：明るい冒険ファンタジーのアニメ塗り。くっきりした線、セル塗りに柔らかい影。彩度は高め、表情豊か。
  ```
- **C. 水彩・絵本風**
  ```
  絵柄：やわらかな水彩画。淡いにじみと紙の質感、細い線。おとぎ話の挿絵のような雰囲気。
  ```
- **D. アール・ヌーヴォー風**（19世紀末の装飾的なポスターの雰囲気）
  ```
  絵柄：アール・ヌーヴォーのポスター風。流れるような輪郭線、平面的で上品な色、髪や布の装飾的な曲線。背景の装飾枠は描かない。
  ```

## 2. 全員の説明（絵柄が決まったら使う）

共通の条件＋選んだ絵柄の指定＋次の説明を1人ずつ。

- **ミラルカ辺境伯**：上記のとおり。
- **カナン卿**
  ```
  キャラクター：カナン卿。老騎士。赤と白の混じった髪、白い髭、赤い瞳、深い皺と鋭い目つき。
  焦げ茶の外套と襟巻き、黒い衣、籠手。剣の柄に手を置いている。普段はとぼけた好々爺、戦では頼れる古強者。
  差し色は赤銅。
  ```
- **堅牢なるオリーヴェ**
  ```
  キャラクター：オリーヴェ。盾を持つメイドの従騎士。青い肌、いつも閉じた目、黒髪の三つ編み。
  フリルのボンネットとエプロンのメイド服、片脚が機械の義足。大きな盾を持つ。丁寧で静かな雰囲気。
  差し色は青。
  ```
- **姫（乙女）**
  ```
  キャラクター：灯台守の見習いの少女。素朴な島の服（生成りのブラウス、紺のスカート、厚手の肩掛け）、手にランタン。
  明るく芯の強い表情。プレイヤーの分身なので、顔立ちは癖の少ない親しみやすい印象に。
  差し色は金（灯の色）。
  ```
- **姫（若人）**
  ```
  キャラクター：灯台守の見習いの少年。素朴な島の服（生成りのシャツ、紺のズボン、短いケープ）、手にランタン。
  明るく芯の強い表情。プレイヤーの分身なので、顔立ちは癖の少ない親しみやすい印象に。
  差し色は金（灯の色）。
  ```

## 3. 統一感を出すコツ

- 1人目ができたら、2人目以降はその画像を添付し、「この画像と同じ絵柄・同じ縮尺・同じ線の太さで」と書き添える。
- 頭の大きさ（何頭身か）を揃えたい場合は「◯頭身」と指定する（例：アニメ塗りなら6頭身）。
- 気に入らない部分は、画像を添付して「髪の色だけ銀に」「表情をもう少し笑顔に」のように部分的に直してもらう。
