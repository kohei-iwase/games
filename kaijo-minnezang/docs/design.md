# 海城のミンネザング 設計メモ：戦略パートと戦闘パート（検討中）

いまの試作（1つの戦場で3隻を操作する戦闘）から、「広い海域で複数の艦隊を動かす戦略パート」と「短い戦闘パート」に分ける方向へ作り変える。この資料はその設計の検討メモ。**【確定】** はユーザーが決めた事項、**【案】** は検討中の提案。

## 0. 方針の転換（2026-10-12）

【確定】
- **プレイヤーは姫**：プレイヤーは新しい姫（プレイヤーの分身。名前を付けられる）。姫は海城の心臓なので、戦略マップの俯瞰は姫の視点、艦隊への指示は姫の声、会話では騎士たちが姫に話しかけ、プレイヤーは選択肢で答える。
- **物語のトーン**：普段はコメディ寄りのファンタジー（参考：ステラソラ、サモンナイト）。掛け合いは軽快に、継承や代償のテーマは要所で一瞬だけ真面目に見せる。見た目（深紅・金・耽美な絵）はそのままにし、中身とのギャップを楽しむ。ドラマの可読性を上げる（下記6章）。
- **戦闘は海戦のオートバトルを見せる**：サマリー表示は廃止し、戦闘の倍速で早送りできるようにする。完全スキップは設定に残す。海戦らしい見せ方（砲撃、艦の動き、カメラワーク）を強化する。
- **姫の立場**：最初は峰の灯の島の普通の市民。プロローグでミラルカに見初められ、ミラルカの海城の心臓になる。性別（姿）を選べ、会話には立ち絵で登場し、心臓になってからは船魂のような存在として城に宿り、人の姿でも活動できる（城の中では幻影として現れることもある）。旧設定の姫ローラは削除。
- **眷属は小さな怪物**：海の小型の怪物が群れで襲ってくる。戦闘は「自軍の艦隊 対 怪物の群れ（複数の敵）」になる。

## 1. 全体の流れ

【確定】戦略マップで艦隊を動かす → 敵艦隊と接触 → 戦闘前の準備 → 短い戦闘（基本オート、ジョストのみ操作）→ 戦略マップに戻る。

【確定】格上の敵と遭遇したとき、プレイヤーが操作すれば勝てる可能性がある、というバランスにする。

## 2. 戦略パート

【確定】
- 広めの海域で、1〜5隻で構成される複数の艦隊を操作する。
- 時間の流れはリアルタイムで、いつでもポーズして指示できる（オウガバトル型）。
- 艦隊の旗艦は名前つきの騎士（姫を持つ）。1つの艦隊に騎士を複数入れてもよい。残りは名前のない随伴艦で数を埋める。戦闘で選べる「スキルの順番」は、艦隊にいる騎士のスキルの並べ方になる。
- スキルで敵を惹きつけたり、マップのギミックを使ったりする。
- 見せ方はいまの3D描画の俯瞰。艦隊は小さな海城の群れで表示し、左上の海図は海域の全体図として残す。
- 最初のステージの勝利条件：ネフェリムと従える敵艦隊が島（峰の灯）を目指す。配下を蹴散らしつつ、ネフェリムを何度かの戦闘で削り切る。島が落ちれば敗北。

【案】
- 戦略スキルの例：オリーヴェの〈不退の誓い〉を「敵艦隊を一定時間こちらへ引き寄せる」に、老騎士カナンの縫い留めを「敵艦隊を数秒止める」に作り替える。敵を浅瀬や罠の地形へ誘い込む。
- ギミックの例：浅瀬（大型の敵が遅くなる）、潮流（流れに乗ると速い）、霧（見えない）、灯台の島（守る対象・補給地）。
- 血を戦略資源にする：戦闘で得た血で姫の心臓が鼓動し、艦隊が動く。補給しないと弱る。

## 3. 戦闘パート

【確定】
- 戦闘は短い。決着は時間制で、与えた損害の割合で勝敗を判定する。負けた側は押し戻される。ボスは何度も戦って削る。
- 開始前に、陣形と使用スキルの順番を選ぶ。
- 開始前に、彼我の予測ダメージ量を表示する。
- 基本はオートで進み、プレイヤーが操作するのはジョストのみ。ジョストを持つのはミラルカの艦隊だけ。ほかの艦隊の戦闘は完全にオート。格上の敵にはミラルカの艦隊をぶつける、という判断が戦略になる。
- スキップした場合は、敵味方の行動をサマリー的に表示し、ジョストの判定だけを行う。
- 設定でジョストも含めて完全にスキップできる。その場合、ジョストは通常射出として計算する。

【案】
- 予測ダメージは、戦闘ルール（`battle.mjs`、画面と切り離されている）を裏で複数回試算して幅で出す（例「与 320〜380 ／ 被 140〜190」）。手動で会心を出した場合の幅も併記し、操作する動機を見せる。
- 格上の敵は「通常射出では僅差で負け、会心を2回出せば勝てる」程度に調整する。会心はダメージが大きいだけでなく、敵の大技を中断させる。

## 4. 最初のステージ「第一歌　血海の誓い」の案【案】

- **海域**：沈みし峰々、ヴァルトブルク峰の沖。いまの戦場の約6倍（横3000×縦2000程度）。西端に峰の灯（守る島）、東の沈んだ谷からネフェリムが浮上する。間に浅瀬・潮流・小島が点在する。
- **自軍の艦隊（2つ）**
  - 主力艦隊：旗艦ミラルカ＋老騎士カナン＋随伴艦1隻。ジョストを持つ唯一の艦隊で、格上（ネフェリム）に当てる。戦略スキル「縫い留め」（老騎士カナン）で敵艦隊を数秒止める。
  - 別働隊：旗艦盾持ちオリーヴェ＋随伴艦2隻。戦略スキル「不退の誓い」で敵艦隊を引き寄せる（囮）。眷属の艦隊を相手にする。
- **敵**
  - ネフェリム（ボス・格上）：単独で島を目指して低速で進む。1回の戦闘では倒しきれず、3〜4回の戦闘で削る。戦闘で負けると押し戻される。浅瀬で大きく遅くなる。
  - 眷属の艦隊（3〜4個、各2〜3隻）：同格〜格下。島へ向かうものと、自軍の艦隊を追うものがいる。
- **随伴艦**：最初は1種類（名前のない海城。旗艦の半分程度の耐久と火力）から始め、種類（砲撃・護衛など）は後で増やす。
- **血**：最初のステージでは戦略資源にしない（戦闘ごとの蓄血は戦闘内で完結）。拡張の段階で検討する。

## 5. 作り方の段階【案】

1. 戦闘パートの短縮化（準備画面・予測・オート・サマリー・スキップ）。いまの戦闘を土台にする。
2. 戦略マップの最小版（2〜3艦隊、敵艦隊数個、接触したら戦闘へ）。
3. 戦略スキルと地形ギミック。
4. 血の資源、複数ステージなどの拡張。

## 6. 物語パート

【確定】
- 見せ方は立ち絵のADV＋演出。会話画面で立ち絵が登場・退場し、話者は前に出て明るく、感情で揺れる・跳ねる・身を引くなどの動きを付ける。
- 入れる場所：ステージの前後（プロローグ・エピローグ）、戦闘の開始・決着時（一言ずつの掛け合い）、拠点での幕間（ステージの合間に、島や海城の中で騎士たちが話す。姫との場面など）。

【案】
- 会話は台本データ（話者・表情・台詞・演出の指定）として持ち、物語用のモジュールで再生する。台本の書式を決めておけば、台詞の追加・差し替えはデータだけで済む。
- 演出の例：登場（左右から滑り込む）、退場、話者の強調（前に出て明るく、他は暗く小さく）、揺れ（驚き・怒り）、跳ね（喜び）、身を引く（怯え・拒絶）、画面の暗転・閃光、背景の切り替え、効果音。
- 表情差分の画像はまだないので、最初は1枚の立ち絵に動きと色味の変化で感情を付ける。

【確定（方針転換）】可読性を上げ、コメディ寄りにする。
- 会話枠は太めのゴシック体で大きく。1台詞は2行まで。地の文は短く。
- 立ち絵の頭上に感情の記号（汗・怒りマーク・音符・！？など）を出す。
- 口調の古風さは味付け程度にする。
