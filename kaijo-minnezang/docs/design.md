# 海城のミンネザング 設計メモ：戦略パートと戦闘パート（検討中）

いまの試作（1つの戦場で3隻を操作する戦闘）から、「広い海域で複数の艦隊を動かす戦略パート」と「短い戦闘パート」に分ける方向へ作り変える。この資料はその設計の検討メモ。**【確定】** はユーザーが決めた事項、**【案】** は検討中の提案。

## 1. 全体の流れ

【確定】戦略マップで艦隊を動かす → 敵艦隊と接触 → 戦闘前の準備 → 短い戦闘（基本オート、ジョストのみ操作）→ 戦略マップに戻る。

【確定】格上の敵と遭遇したとき、プレイヤーが操作すれば勝てる可能性がある、というバランスにする。

## 2. 戦略パート

【確定】
- 広めの海域で、1〜5隻で構成される複数の艦隊を操作する。
- 時間の流れはリアルタイムで、いつでもポーズして指示できる（オウガバトル型）。
- 艦隊の旗艦は名前つきの騎士（姫を持つ）。残りは名前のない随伴艦で数を埋める。
- スキルで敵を惹きつけたり、マップのギミックを使ったりする。

【案】
- 戦略スキルの例：オリーヴェの〈不退の誓い〉を「敵艦隊を一定時間こちらへ引き寄せる」に、カナン卿の縫い留めを「敵艦隊を数秒止める」に作り替える。敵を浅瀬や罠の地形へ誘い込む。
- ギミックの例：浅瀬（大型の敵が遅くなる）、潮流（流れに乗ると速い）、霧（見えない）、灯台の島（守る対象・補給地）。
- 血を戦略資源にする：戦闘で得た血で姫の心臓が鼓動し、艦隊が動く。補給しないと弱る。

## 3. 戦闘パート

【確定】
- 戦闘は短い。決着は時間制で、与えた損害の割合で勝敗を判定する。負けた側は押し戻される。ボスは何度も戦って削る。
- 開始前に、陣形と使用スキルの順番を選ぶ。
- 開始前に、彼我の予測ダメージ量を表示する。
- 基本はオートで進み、プレイヤーが操作するのはジョストのみ。
- スキップした場合は、敵味方の行動をサマリー的に表示し、ジョストの判定だけを行う。
- 設定でジョストも含めて完全にスキップできる。その場合、ジョストは通常射出として計算する。

【案】
- 予測ダメージは、戦闘ルール（`battle.mjs`、画面と切り離されている）を裏で複数回試算して幅で出す（例「与 320〜380 ／ 被 140〜190」）。手動で会心を出した場合の幅も併記し、操作する動機を見せる。
- 格上の敵は「通常射出では僅差で負け、会心を2回出せば勝てる」程度に調整する。会心はダメージが大きいだけでなく、敵の大技を中断させる。

## 4. 作り方の段階【案】

1. 戦闘パートの短縮化（準備画面・予測・オート・サマリー・スキップ）。いまの戦闘を土台にする。
2. 戦略マップの最小版（2〜3艦隊、敵艦隊数個、接触したら戦闘へ）。
3. 戦略スキルと地形ギミック。
4. 血の資源、複数ステージなどの拡張。

## 5. 未決事項

- ジョストを操作できるのはミラルカの艦隊だけか、各騎士に「決め技」のタイミング入力を持たせるか
- 戦略マップの見せ方（いまの3D描画を俯瞰で使うか、2Dの海図で作るか）
- 1ステージの勝利条件（ボス撃破、島の防衛、目的地への到達など）
- 最初のステージの規模（自軍の艦隊数、敵艦隊の数と種類）
- 随伴艦の種類と役割（砲撃艦、護衛艦など）
- 血の資源を入れるか
- いまの試作（1戦場の戦闘）をどこまで残すか
