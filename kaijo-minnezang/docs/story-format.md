# 台本の書き方

物語パートの会話は、`dist/story/` に置いたテキストファイル（拡張子 `.txt`、文字コードは UTF-8）で書く。1ファイルが1場面。ゲームがこのファイルを読み、立ち絵の会話として再生する。

## 書式

1行に1つの指示か台詞を書く。空行は無視する。

| 書き方 | 意味 |
|---|---|
| `# 〜` | コメント（再生しない） |
| `名前［感情・動き］台詞` | 台詞。`［］` は省略できる。感情と動きは `・` で区切り、どちらか片方だけでもよい |
| `＊台詞` | 地の文（ナレーション）。名前の札を出さない |
| `@背景 海` | 背景。`海`（ぼかした海の絵）／`海図`（同じ絵を暗めに）／`暗転`（真っ暗） |
| `@登場 名前 左` | 立ち絵を出す。位置は `左`・`中`・`右` |
| `@退場 名前` | 立ち絵を下げる |
| `@見出し 見出し｜副題` | 場面の見出しカード。背景の上に左から帯が滑り込み、大きな見出しと小さな副題を約2.2秒出して消えてから、次へ進む（クリック・Space で早送り）。副題は省略でき、`｜` は半角 `|` も可。場面の冒頭に置く |
| `@空気 潮風` | 場所の空気。会話中ずっと続く粒子の演出と環境音（ループ）を出す。`潮風`（飛沫が画面を横切る・波と風の音）／`夜の港`（灯の粒が昇って明滅・遠い槌音と小さな波音）／`地鳴り`（滴が落ちる・時々画面が揺れる・低い地鳴り）／`なし`（止める）。会話が終わると止まる |
| `@演出 閃光` | 画面の演出。`閃光`・`暗転`・`明転`・`揺れ` |
| `@音 鐘` | 効果音。`鐘`・`鼓動`・`杭`・`十字架`・`打撃` |
| `@間 0.8` | 指定した秒数だけ待つ |
| `@選択 A｜B｜C` | 選択肢を出す（`｜` で区切る。半角 `|` も可）。続く `@もし 1`〜`@ここまで` で、選んだ番号ごとの台詞を書く |
| `@もし 1` | 直前の `@選択` で1番目を選んだときだけ、次の `@もし` か `@ここまで` までを再生する |
| `@ここまで` | 選択肢の分岐の終わり |
| `@名前入力` | プレイヤーに姫の名前を入力してもらう（以後 `{姫}` に入る） |
| `@姿 人` | プレイヤー（姫）の姿を切り替える。`人`（人の姿）／`幻影`（半透明の船魂の姿） |

- 台詞の中の `／` は改行になる。
- `（〜）` で囲んだ台詞は心の声として、少し淡く表示する。
- 全角の `［］` の代わりに半角の `[]` も使える。
- 台詞・選択肢の中の `{姫}` は、プレイヤーが付けた姫の名前に置き換わる。

## 名前

短い名前でも、表示名でも書ける。

| 書く名前 | 表示名 | 立ち絵 |
|---|---|---|
| `ミラルカ`、`ミラルカ辺境伯` | ミラルカ辺境伯 | あり |
| `カナン`、`老騎士カナン`（旧名 `カナン卿` も可） | 老騎士カナン | あり |
| `オリーヴェ`、`盾持ちオリーヴェ`（旧名 `堅牢なるオリーヴェ` も可） | 盾持ちオリーヴェ | あり |
| `姫` | プレイヤーが付けた名前 | プレイヤーが選んだ姿（性別）。`@姿` で人／幻影 |
| それ以外（例：`見張り`） | 書いたとおり | なし（名前の札だけ） |

## 感情と動き

表情差分の画像はまだないので、感情は立ち絵の色味と動きで表す。

- 感情：`喜び`・`怒り`・`驚き`・`哀しみ`・`静か`・`凛`・`照れ`・`不敵`・`焦り`・`呆れ`・`得意`
- 動き：`跳ねる`・`揺れる`・`身を引く`・`前に出る`・`震える`・`頷く`

動きを書かなかった場合は、感情に応じた動きが付く（例：`喜び`→小さく跳ねる、`驚き`→身を引く、`怒り`→揺れる、`焦り`→震える）。

感情によって、立ち絵の頭上に記号が出る：`喜び`→♪、`怒り`→怒りマーク、`驚き`→！？、`哀しみ`→…、`照れ`→♡、`焦り`→汗、`呆れ`→…（汗）、`得意`→✦。ほかの感情は記号なし。

読みやすさのため、1つの台詞は2行（`／` 1回）までにする。話している人の立ち絵は前に出て明るくなり、ほかの人は少し暗くなる。

## 立ち絵の配置

画面に立つ立ち絵は同時に2人まで。1人のときは中央やや右、2人のときは左右に並ぶ。`@登場` の位置（左・中・右）は「2人のときの並び」の希望で、`中` は空いている側になる。登場・退場・入れ替わりは、その場でのフェード（横からは滑り込まない）。3人目が登場すると、最も長く話していない人が自動で退場し、その場所に入れ替わるが、台本では `@退場` を書いて2人までに整理しておく。話者が画面にいない（立ち絵が出ていない）ときは、台詞枠の左に顔のアイコンが出る（切り出す位置は `story.mjs` の `CHARACTERS` の `face=[x%,y%,倍率]`）。記号は白い吹き出しで出て、小さな音が付く（`哀しみ`・`呆れ` の「…」は3つの点が順に光る）。

## 例

```
# 例
@背景 海
＊海が山を呑んでから、幾つの夜が過ぎただろう。
@登場 ミラルカ 中
ミラルカ［喜び・跳ねる］全艦、ボクに続け！
ミラルカ［静か］（……今度こそ、守ってみせる）
@演出 閃光
```

## 場面の一覧

| ファイル | いつ流れるか |
|---|---|
| `prologue.txt` | ゲームの開始時（プロローグ） |
| `contact-nephilim.txt` | ネフェリムと初めて接触したとき（準備画面の前） |
| `interlude-lamp.txt` | 主力艦隊が初めて峰の灯で補給したとき（幕間） |
